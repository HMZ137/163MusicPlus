# 163MusicPlus v44 发行说明（草稿 · 2026-11-22）

> 自 v43（2026-11-21 上传）以来的全部变更。
> 发布前请按「已知问题」一节确认字幕与收藏专辑两项的实测状态。

---

## 新增

**设置**
- 分类设置页（外观与显示 / 播放与音质 / 交互与浮层 / 数据与工具）新增**引导简介**，一眼看清这一页有哪些设置项
- 每个设置项的灰色说明文字改为**折叠一行**，点灰色文字本身即可展开完整说明；首次进入设置会有一次性提示（5 秒后方可关闭）

**主题**
- 新增「**网易云红**」主题（`#FC3D49`）

**B 站（听bilibili）**
- 支持**账号登录**：扫码登录 / 直接粘贴 Cookie 登录（兼容 `{"cookies":"..."}` 格式）
- 登录后入口长期显示「**已登录：昵称**」，不必点进去确认
- 听 bili 页新增**在线收藏**入口
- 主界面播放选项（B 站视频）新增「**复制链接**」——复制的是分享页地址，不是播放直链

**表冠**
- 「表冠灵敏度」改为**自定义倍率**：默认 ×1，可自行输入 0.1~5.0，转同样的角度按倍率缩放音量变化

**收藏**
- 收藏歌曲多选动作栏新增「**收藏到歌单**」（与「加入本地歌单」并列，走云端歌单）
- 首次进入收藏页弹出「哪些页面可以长按」提示（5 秒后方可关闭）

## 修复

**表冠音量**
- 修复「向上转第一步却是音量减小」：原实现用「累计位移到阈值」判定方向，会被起转时的反向小 kick 带偏。改为**连续增量模型**——每个事件的带符号增量直接累加，UI 同帧更新，系统音量档位变化才写入

**收藏**
- 修复**收藏歌曲封面永远显示默认占位图**：收藏记录持久化时没有保存封面字段，且补详情时的「本地优先」会把远端带回封面的数据整条丢弃；现在存/读都带 `cover`，并用远端数据补全本地记录的缺失字段
- 修复**收藏的专辑不显示**：`/api/album/sublist` 的响应层级解析错误（`total` 能读到但数组为 0 条），已修正并加解析日志

**设置**
- 修复**标题被裁成半个汉字**：设置页标题、开关行标题统一改为自适应字号
- 修复**行背景涟漪只出现在最后一行**：Drawable 缓存改为 `ConstantState` + `newDrawable()`，各行状态独立

**B 站**
- 修复**搜索搜不到任何结果**：搜索接口从 `/wbi/search/type` 换为 `/wbi/search/all/v2`（取其中的 video 分组），并补 WBI 签名
- 修复**听 bili 页没有返回入口**：改为显示全局浮动返回按钮，同时移除标题栏箭头避免重复
- 修复**应用内左滑返回默认关闭**：默认开启

## 优化

- **收藏 ID 数组内存缓存**：`isFavorite` 不再每次都读文件 + 解析 JSON（该方法被 6 处频繁调用，主界面浮层点开的卡顿主要来自这里）
- **设置页行背景 Drawable 缓存**：从每行新建改为整页复用一份常量
- **设置页打开速度**：分类页构建耗时已加日志（`adb logcat -s SettingsPerf`），后续按数据继续优化
- 开源信息页开发者署名修正为 **HMZ138**（本项目）/ **qinghe**（上游 163MusicPro）

## 移除

- **全屏歌词**整体下线：设置里的「全屏歌词按钮」开关、歌词设置菜单里的「全屏歌词」入口、全屏歌词页（`LyricsActivity`）全部移除
- **「开关选项」页**整体下线：全部设置项已按分类合并到各设置页，原页面与其入口一并删除（用户已有设置值不受影响）

## 已知问题 / 待确认

1. **B 站中文字幕歌词**：字幕接口已补 WBI 签名，未登录时会明确提示「获取字幕需要登录 B 站账号」；登录后能否稳定拿到仍需实测确认（部分视频为 AI 字幕）
2. **收藏专辑**：解析已修正，但设备侧 `count=0 / total=10` 的原始响应结构尚未最终确认，发布前需再验一次
3. **设置页打开耗时**：实测 8 行页 284ms、15 行页 414ms，固定开销约 250ms，瓶颈疑在基类初始化；详细分析见 `docs/性能分析-设置页-20261122.md`
4. **release 构建性能**：以上耗时均为 debug 构建，release 下会明显更快，尚未做对照
